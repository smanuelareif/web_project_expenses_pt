# TripleTen web_project_expenses

Projeto desenvolvido durante o curso de Desenvolvimento Web da TripleTen.

## Sobre o projeto

O **Web Project Expenses** é um rastreador de despesas desenvolvido com **HTML, CSS e JavaScript**. O projeto permite definir um orçamento, adicionar e excluir despesas e acompanhar estatísticas financeiras de forma dinâmica.

Entre as funcionalidades implementadas estão o cálculo do total e da média das despesas, cálculo do saldo disponível, alteração da cor do saldo de acordo com a situação financeira, agrupamento de despesas por categoria e identificação da categoria com maior gasto.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
